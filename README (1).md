# ระบบส่งผลงาน Best Practices 🏆 (เว็บฟอร์ม)

ระบบรับสมัครและตัดสินผลงาน **Best Practices นวัตกรรมการจัดการเรียนรู้ภาษาอังกฤษเพื่อการสื่อสาร บูรณาการใช้ปัญญาประดิษฐ์** ระดับชั้น ม.3
โรงเรียนในสังกัด **สำนักงานเขตพื้นที่การศึกษาประถมศึกษาอุดรธานี เขต 1**

เป็น **หน้าเว็บฟอร์มของเราเอง** ที่รับข้อมูลและไฟล์จากครู แล้วบันทึกลง **Google Sheet** เป็นฐานข้อมูล และเก็บไฟล์ลง **Google Drive** โดยตรง (ไม่ใช้ Google Form)

---

## สถาปัตยกรรม

```
หน้าเว็บ index.html  →  Google Apps Script (Web App)  →  Google Sheet + Google Drive
```

ครูกรอกฟอร์มบนหน้าเว็บ แนบไฟล์ WORD/PDF และลิงก์คลิปวิดีโอการสอน → ระบบส่งไปที่ Apps Script (ตัวกลาง) → บันทึกข้อมูลลงชีต `การส่งผลงาน` และเก็บไฟล์ลงโฟลเดอร์ Drive อัตโนมัติ พร้อมชีต `ให้คะแนน` / `สรุปผล` / `เกณฑ์การให้คะแนน` สำหรับกรรมการ

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|---------|
| [`index.html`](./index.html) | หน้าเว็บฟอร์มรับผลงาน (front-end) — ใช้เป็นหน้าเว็บสาธารณะผ่าน GitHub Pages ได้ |
| [`Code.gs`](./Code.gs) | หลังบ้าน (Apps Script Web App) — รับข้อมูล เก็บไฟล์ เขียนฐานข้อมูล + สร้างชีตคะแนน |
| [`guide.html`](./guide.html) | คู่มือติดตั้งภาษาไทยพร้อมปุ่มคัดลอกโค้ด |

---

## วิธีติดตั้ง

**A. หลังบ้าน (Apps Script)**

1. เข้า [script.google.com](https://script.google.com) → โครงการใหม่ → วางเนื้อหา `Code.gs` → บันทึก
2. เลือกฟังก์ชัน `ติดตั้งระบบ` → กด ▶ Run → อนุญาตสิทธิ์ → ดูลิงก์ Sheet/โฟลเดอร์ที่ Execution log
3. เมนู **Deploy → New deployment → Web app** → Execute as: **Me** · Who has access: **Anyone** → Deploy
4. คัดลอก **Web app URL**

**B. หน้าเว็บ**

5. เปิด `index.html` แก้บรรทัด `const WEBAPP_URL = "..."` ใส่ Web app URL ที่ได้ → บันทึก
6. เผยแพร่หน้าเว็บ: เปิด **Settings → Pages** ของ repo นี้ → Branch: `main` → Save จะได้ลิงก์เว็บสาธารณะ
