# ระบบส่งผลงาน Best Practices 🏆

ระบบรับสมัครและตัดสินผลงาน **Best Practices นวัตกรรมการจัดการเรียนรู้ภาษาอังกฤษเพื่อการสื่อสาร บูรณาการใช้ปัญญาประดิษฐ์** ระดับชั้น ม.3
โรงเรียนในสังกัด **สำนักงานเขตพื้นที่การศึกษาประถมศึกษาอุดรธานี เขต 1**

ระบบทำงานบน **Google Form + Google Sheet** ล้วน ๆ ติดตั้งด้วย Google Apps Script เพียงกดรันครั้งเดียว

---

## ระบบทำอะไรให้บ้าง

| ส่วน | รายละเอียด |
|------|------------|
| 📝 **ฟอร์มรับผลงาน** | ครูกรอกชื่อผลงาน / ผู้เสนอ / ตำแหน่ง / โรงเรียน / สังกัด / เบอร์โทร และ **แนบไฟล์ WORD + PDF ผ่านระบบได้เลย** |
| 📊 **ฐานข้อมูล Google Sheet** | ข้อมูลและไฟล์ที่ครูส่งไหลเข้า Sheet อัตโนมัติ |
| ✅ **ให้คะแนนอัตโนมัติ** | กรรมการกรอกระดับ 1–3 ของ 8 องค์ประกอบ (90 คะแนน) + แผนการสอน (10 คะแนน) → ระบบรวมเป็น 100 และตัดระดับคุณภาพให้เอง |
| 📈 **สรุปผล** | นับจำนวนผลงาน แยกตามระดับคุณภาพ หาคะแนนสูงสุด / ผู้ชนะเลิศ อัตโนมัติ |

## วิธีติดตั้ง (ทำครั้งเดียว ~3 นาที)

1. เข้าเว็บ [script.google.com](https://script.google.com) แล้วล็อกอินด้วยบัญชี Google ที่จะใช้รับผลงาน
2. คลิก **โครงการใหม่ / New project**
3. ลบโค้ดเดิมออกให้หมด แล้ววางเนื้อหาจากไฟล์ [`Code.gs`](./Code.gs) ทั้งหมด
4. กดบันทึก 💾 → เลือกฟังก์ชัน **`สร้างระบบBest`** → กด **▶ Run**
5. ครั้งแรกจะให้ **อนุญาตสิทธิ์ (Authorize)** → เลือกบัญชี → Advanced → ไปที่โครงการ → อนุญาต
6. เปิด **มุมมอง → บันทึกการทำงาน (Execution log)** จะเห็น **ลิงก์ฟอร์ม** และ **ลิงก์ Google Sheet**

> 💡 ส่ง **ลิงก์ฟอร์ม** ให้ครูส่งผลงาน · เก็บ **ลิงก์ Sheet** ไว้ให้กรรมการตรวจให้คะแนน (เชื่อมกันอัตโนมัติแล้ว)

คู่มือฉบับเต็มพร้อมภาพประกอบดูได้ที่ไฟล์ [`guide.html`](./guide.html)

| 3.2 กระบวนการจัดการเรียนรู้ (CLT+AI) | ×4 | 12 |
